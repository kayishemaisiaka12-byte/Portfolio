# Kayishema Isiaka — Quality Engineering Portfolio

A responsive, single-file portfolio website for QA leadership, application support, API testing, test automation, and CI/CD quality.

## Website
This site is built as a self-contained `index.html` with embedded styling and JavaScript, so no build tools or extra assets are required.

## Publish with GitHub Pages
1. Open the repository **Settings → General → Danger Zone** only if you need to change visibility. Choose **Change visibility → Make public** and confirm. Do not publish any confidential information.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. After deployment completes, the site should be available at `https://kayishemaisiaka12-byte.github.io/Portfolio/` (if GitHub Pages is enabled for this repository). Publishing may take several minutes.

GitHub Pages is available for public repositories on GitHub Free. See https://docs.github.com/en/pages/quickstart.

## Privacy and accuracy
- The portfolio intentionally uses high-level project summaries.
- Do not add banking data, internal URLs, credentials, customer information, or proprietary test evidence.
- Confirm all skills and project claims are accurate before sharing with employers.
- Review the email and profile links in the site before publishing.
